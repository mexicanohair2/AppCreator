Как опубликовать HTML-проект

1. Поместите все файлы сайта или игры в папку www/ репозитория.
2. Главный файл должен называться index.html.
3. Откройте GitHub Actions и запустите Publish HTML to URL.
4. После успешной публикации получите общедоступную ссылку GitHub Pages.

Открыть публикацию и сборки ↗

Ссылка появится после первого успешного запуска публикации. Для обновления сайта запустите её снова.
